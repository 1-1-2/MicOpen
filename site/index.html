Android × Windows · Wi-Fi

把手机，变成
Windows 麦克风。

MicLink Open 把 Android 手机的麦克风音频送进 Windows。手机负责采集和编码，Windows 客户端接收后写入虚拟录音设备，供录音软件直接选择。

Four steps · One audio path

从手机说话，到电脑收到声音。

两端各做一件事，链路状态在客户端可见。产品音频走设备间网络，不经 MicLink 云服务。

01 / CAPTURE

手机开始采集

Android 使用系统录音接口取得麦克风音频。

02 / ENCODE

编码并发送

按 手机采集 · Windows 接收协商，音频通过 UDP/Opus 发送。

03 / RECEIVE

Windows 解码

客户端显示连接、音量和会话信息，再把 PCM 写给驱动。

04 / SELECT

选择录音设备

录音应用选择 WO Mic 虚拟麦克风端点即可采集。

ⓘ使用前先安装兼容的 WO Mic 驱动。MicLink Open 负责采集、连接和音频接收，第三方组件说明见 NOTICE。
