# 直连角色实验的分支安排

| 位置 | 用途 |
|---|---|
| `main` / v0.1.2 | 已发布的 Wi-Fi、热点、蓝牙、USB 基线 |
| `522cc3e` | 初次引入 Wi-Fi Direct 与 Wi-Fi/热点合并；没有后续日志与 UI 修复 |
| `feat/wifi-direct` / `221f54c` | 手机 GO、电脑搜索选择；保留现有实机失败记录，不改写 |
| `feat/wifi-direct-phone-initiated` | 从 `221f54c` 分出；电脑 GO 等待、手机搜索选择 |

选择最新已验证节点，不把新方向叠成旧选择流程上的额外开关。原因：日志、设置入口、主题及 CI 变更交错在多个历史提交内；从最初节点重排会重复移植并容易遗漏修复。保留共同祖先能直接比较两个方向的 transport 差异，同时完整保留已交付日志能力。稳定主线不因此变化。

新分支只替换直连发现、建组与地址取得；音频控制端仍保持电脑连接手机，协议、驱动与编码不改。Windows 独立 DLL 变更为监听 ABI 3，Android transport 返回同一个“本机实际 IPv4 就绪”回调。日志相关 UI 不再重做。

今后公用修复提交应独立于角色实验，便于双方挑选；需要合并双模式时，再抽取共享传输能力接口与显式角色协调。当前保留公开提交顺序与旧分支历史。实机确认前不发布 Release。

应用提交 `0bb8491` 已通过 [CI 40874849894](https://github.com/1-1-2/MicOpen/actions/runs/40874849894) 的 10 个任务。当前仅交付双端测试包，未创建 Release，未合入 `main`；无线实体发现、配对和音频仍待作者验收。
