# 人工互操作检查

本项目 Android app 与 Windows 接收端已通过 CI 配对验证。与第三方官方客户端或 app 的互操作需要单独执行并记录版本，不能由本项目两端互通推导为已通过。

用户已确认 Wi-Fi、手机热点、蓝牙与有线 ADB / USB 的基本实机链路可用；这不替代下表中的系统音效、音质、后台保活或官方客户端互操作逐项检查。

## 前提

记录 Windows、Android、驱动、app 和客户端版本，确认手机与电脑网络可达，并使用已安装的兼容驱动。先用本项目两端确认设备和网络正常，再替换其中一端进行对照。

## 操作

| 组合 | 检查项 | 当前记录 |

| 本项目 Android app 与官方 Windows Client | 连接、持续收音、停止、重连 | 待人工执行 |
| 官方 Android app 与本项目 Windows 接收端 | 连接、收包、电平、录音、停止 | 待人工执行 |

录音检查使用正常讲话或明确频率的调试音，记录输入设备、录音文件、持续时间与异常现象。发生问题时分别确认控制连接、媒体接收和录音端点，避免只根据界面“已连接”判断音频链路。
